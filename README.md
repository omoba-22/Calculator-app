# MS Native Calculator (Web Version)

A clean, responsive, and fully functional **Microsoft-style Calculator** built with **HTML, CSS, and JavaScript**.  
This project recreates the look and feel of the Windows Calculator, including a sidebar, history panel, and memory tab.


## Features

### Windows-Style Interface
- Standard MS Calculator layout  
- Sidebar menu with:
  - Standard  
  - Scientific  
  - Graphing  
  - Programmer  
  - Date calculation  

- Converter types such as:
  - Currency  
  - Volume  
  - Length  
  - Weight & Mass  
  - Temperature  
  - Area  
  - Speed  
  - Time  
  - Power  
  - Data  
  - Pressure  
  - Angle  


## Calculator Functions

Fully supports essential operations:

- Addition (+)  
- Subtraction (−)  
- Multiplication (×)  
- Division (÷)  
- Percentage (%)  
- Negate (+/−)  
- Square (x²)  
- Square root (√x)  
- Reciprocal (1/x)  
- Clear (C & CE)  
- Delete/Backspace (⌫)  
- Equals (=)

Includes:
- Subscreen for expressions  
- Main screen for results  

##  History & Memory Panel

Right-side panel includes:

- **History Tab** — logs previous calculations  
- **Memory Tab** — placeholder UI for memory functions  

Smooth tab switching and responsive layout.
